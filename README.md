# Nson Tech Innovation Website

A responsive, single-page product website built with plain HTML, CSS, and JavaScript.

## Open in VS Code

1. Extract `nson-tech-website.zip`.
2. Open the extracted `nson-tech-website` folder in VS Code.
3. Open `index.html` in a browser, or install the **Live Server** VS Code extension and click **Go Live**.

No package installation or build command is required.

## Files

- `index.html` — page content and sections
- `styles.css` — layout, colors, responsive design, and animation
- `script.js` — mobile navigation, scroll effects, form validation, and contact action
- `assets/home-automation-controller.jpg` — controller product photo
- `assets/home-automation-controller-overview.jpg` — controller interface overview
- `assets/home-automation-controller-datasheet.pdf` — product datasheet

## Before publishing

The published contact email is `nsontechinnovation@gmail.com`.

The contact form currently validates the visitor's entries and opens their email application using `mailto:`. For submissions that work without an email app, connect the form to a service such as Formspree, Netlify Forms, or your own server endpoint.

Review the company description and technical specifications before publishing to ensure every statement matches the final production unit. The datasheet notes that relay contact ratings do not by themselves establish the complete assembly rating for household mains loads.

## Publish options

You can upload the folder to GitHub Pages, Netlify, Cloudflare Pages, or any standard web host. The entry file is `index.html`.
